Это учебный проект в рамках изучения Теории автоматов:
Библиотека реализующая регулярные выражения на c++


С попыткой соблюдать ООП и RAII) А также покрытая тестами

Функции

search(const string& reg, const string& text) Позволяет найти первую подходящую под шаблон подстроку в строке

Возвращает объект Output_reg. это контейнер, по индексу 0 хранится найденная подстрока, далее лежат значения групп.
объект итерируемый, можно обращаться к группе по имени

compile(string reg) Позвлоляет скомпилировать регулярное выражение в автомат для многократного использования. 
Возвращает объект Pattern, имеющий функцию search

Синтаксис, где r1, r2 регулярные выражения

r1|r2 = ИЛИ

r1r2 = Конкатенация

r1{n} = Повтор n раз

r1... = Замыкание Клини(повтор 0 или более раз)

r1? = Опциональная часть

()=Повышение приоритета

(<name>r1)=Группа захвата

%some_text% = экранирование, Для написания %, используй %%


Библиотека использует минимизированные Детерминированные Конечные автоматы для регулярных выражений без групп

Группы захвата реализованы на уровне Недетерминированного Конечного автомата

Библиотека сама подбирает нужный автомат под выражение

Есть функция recover_reg, которая использует алгоритм k_path для восстановления регулярки по ДКА

В будущем программа будет дорабатываться, нужно добавить операции над автоматами, а ещё я планирую заняться оптимизацией алгоритмов
